# ViMotion: новый лендинг

Лендинг менторской программы Валентина Сушнёва по контенту для бизнеса. Структура и тексты утверждены клиентом, сейчас этап визуала.

## С чего начать

1. `PROJECT_INSTRUCTIONS.md`: как устроена работа по блокам.
2. `DESIGN_BRIEF.md`: стиль, цвета, шрифты, правила, идеи для блоков 1-3.
3. `ASSETS.md`: какие фото есть, каких не хватает.
4. `content/prototype.html`: открыть в браузере, это утверждённый прототип.
5. `content/copy.md`: тексты по блокам.

## Структура

```
content/   прототип, тексты, PDF с анализом
assets/    фото Валентина, учеников, доказательства, медиа, логотип
refs/      драфт сайта, слайды презентации, референс Varfolomeev, правки клиента
site/      готовый сайт (собираем по блокам)
```

## Сборка главной (с 21.11)

Главная собирается из исходников: правки вносить в `site/index.src.html`, `site/styles/blocks/*.css`, `site/scripts/*.js`, затем

    python3 tools/build.py

Скрипт склеивает все стили в `site/styles/site.css`, все скрипты в `site/scripts/site.js` и пишет `site/index.html` с одной версией `?v=` по хешу. Страница кейсов `site/cases.html` подключает файлы напрямую.
