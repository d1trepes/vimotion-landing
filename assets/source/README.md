# Новый исходник первого экрана

`racer-original.mp4` — исходный файл `gemini_generated_video_6ca61124.mp4`, переданный владельцем сайта 16 ноября 2026. Скопирован без перекодирования. Это новый ролик, а не исходник прежнего шестисекундного видео.

- Исходник: 1280×720, 24 FPS, 240 кадров / 10 секунд; оригинальный AAC сохранён здесь.
- Фон удалён заранее через Robust Video Matting (MobileNetV3 FP32 ONNX, downsample_ratio=0.5, последовательные recurrent states). Модель: https://github.com/PeterL1n/RobustVideoMatting
- Пиксели внутри непрозрачного человека взяты из оригинала; предсказанный foreground используется у полупрозрачного края для уменьшения бежевого ореола.
- Кадрирование фиксированное: x=268, y=30, width=744, height=690. Лицо, одежда и движение не генерируются, FPS не увеличивается.
- `site/media/valentin-live.mp4`: H.264, CRF 17, slow, 24 FPS, 744×1380. Верх — цвет 744×690, низ — маска того же размера.
- `site/media/valentin-live-m.mp4`: такой же размер и FPS, CRF 20. Цветная часть увеличена относительно прежних 496×460, чтобы меньше терять качество на экранах с высоким DPR.
- Оба веб-файла без аудио (декоративное видео), с faststart. Звук оригинала остаётся в исходнике.
- `site/img/valentin-poster.webp`: первый кадр нового видео, lossless WebP RGBA. Альфа согласована с существующим smoothstep в шейдере.
- HTML, CSS и JavaScript не изменялись. Названия и формат ассетов совместимы с существующим проигрывателем, постером и reduced-motion.

Предел детализации остаётся у исходника 720p; увеличение изображения на большом экране не создаёт настоящие 4K-детали. Matting оценочный: тонкие волосы требуют визуальной проверки. Исходные 10 секунд сохранены; бесшовность стыка конца и начала не гарантируется.

Папка `assets/source/` не входит в публикацию GitHub Pages: workflow публикует только `site/`.

Проверки: оба MP4 полностью декодированы (240 кадров, 24 FPS, 10 секунд). В Chromium проверены ширины 1440/1024/390 px (на телефоне DPR=2), отсутствие горизонтального переполнения, загрузка нужного файла и постера. Проверены fallback при reduced-motion, недоступном WebGL и запрещённом autoplay. Реальные iPhone/Safari отдельно не проверялись.
